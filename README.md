## Рекомендации к выполнению проектов

- Использовать актуальную версию PostgreSQL
- Писать SQL-запросы в удобной среде разработки (DataGrip, DBeaver, pgAdmin и др.)
- В репозитории должны оставаться только файлы, указанные в заданиях
- Настроить `.gitignore`, чтобы исключить лишние файлы
- Перед началом работы развернуть предоставленную модель базы данных **[model.sql](./model.sql)**
