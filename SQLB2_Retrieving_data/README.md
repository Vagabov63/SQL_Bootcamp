# SQLB2_Retrieving_data

## Суть проекта

В данном проекте реализован комплекс SQL-запросов для работы с реляционной базой данных сети пиццерий. База данных включает пять связанных таблиц: справочники пиццерий, клиентов и меню, а также журналы посещений и заказов.
Основная цель — отработать ключевые навыки работы с SQL:
- фильтрацию данных по различным условиям (города, даты, диапазоны значений);
- сортировку с разными направлениями по нескольким полям;
- создание вычисляемых полей с условной логикой (`CASE`);
- использование вложенных подзапросов в секциях `SELECT` и `FROM`;
- формирование строковых значений по заданному шаблону;
- работу с уникальными значениями и чётными идентификаторами.

Все запросы выполнены без использования `JOIN` там, где это требовалось условиями, что позволило глубже освоить альтернативные подходы к получению связанных данных через подзапросы. Результаты охватывают широкий спектр типовых задач анализа данных — от простых выборок до многоуровневых вложенных конструкций.
